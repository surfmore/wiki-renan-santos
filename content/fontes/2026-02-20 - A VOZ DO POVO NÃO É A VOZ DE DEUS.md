## Resumo

Em entrevista, Renan defende uma posição que pode parecer impopular: se o povo reelege um prefeito que não cumpriu indicadores básicos (esgoto, educação, saúde), o povo está errado e a solução é impor um **interventor** independentemente do resultado eleitoral.

> "A voz do povo não é a voz de Deus. O povo quer show."

O argumento não é antidemocrático, segundo Renan: a democracia precisa de incentivos corretos para funcionar. O problema é que o sistema atual permite que políticos sejam reeleitos sem entregar resultados. A proposta é criar um sistema de **avaliação por indicadores objetivos** que substitua a reeleição automática como mecanismo de prestação de contas.

O interlocutor levanta uma objeção: os próprios políticos que deveriam votar para implementar o novo sistema são os mesmos que se beneficiam do atual. Renan reconhece o dilema e propõe a saída: um presidente que entre no poder com **popularidade suficiente para derrotar o crime organizado** terá capital político para impor essas reformas. Esse presidente resolveria o Brasil para os próximos 30 anos, porque mudaria o sistema de incentivos políticos estruturalmente.

> "Se não passar isso, o Brasil quebra, porque o modelo de Brasil que nós temos hoje faz com que a classe política seja a maior inimiga do país. É para botar político para trabalhar. Ponto."
